# Archive — April 2026

Early artifacts, superseded by the current model.

- `MicroROS_Schematic.sysml.txt` — first SysML sketch of the system
- `MicroROS_Schematic_sysml.pdf` — a rendering of it

The `.sysml` file is stored with a `.txt` extension because it uses `state` as an
identifier, which is a reserved word in HAMR 4.20260810. With the original extension it
is discovered as model source and fails the project-root type check. See
[../Noteworthy.md](../Noteworthy.md).

The current model is [`sysmlv2/SeedImaging.sysml`](../../sysmlv2/SeedImaging.sysml).
